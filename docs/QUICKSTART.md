# Início rápido

Execute `scripts/run.ps1` no Windows ou os comandos de ambiente virtual do README em outros sistemas. Copie `.env.example` para `.env` para personalizar a instalação.

Crie uma conta, configure Minha busca e ative as fontes em Fontes e atualização. Clique em coletar e verifique a cobertura e os avisos. Resultados fora dos critérios permanecem no catálogo para comparação; o filtro da sua busca é explícito.

Uploads passam por uma prévia: somente Confirmar grava. Para migrar sua planilha antiga local, coloque `resultados_quintoandar.xlsx` na raiz e habilite `IMOVEL_ENABLE_LEGACY_IMPORT=1`; essa conveniência está restrita à primeira conta. O arquivo é privado, ignorado pelo Git e não acompanha o projeto.

Nenhuma configuração pessoal é atribuída automaticamente a contas novas. Alterações de preferência não apagam seus imóveis, notas ou histórico.
